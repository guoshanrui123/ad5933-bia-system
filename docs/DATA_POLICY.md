# 数据提交规则

## 可以提交

- 固件与Python源代码；
- 不含受试者信息的台架校准负载数据；
- 校准模型结构、验证方法和匿名汇总；
- 使用说明和可复现构建配置。

## 禁止提交

- 人体原始TXT和逐轮数据；
- 医院记录Excel；
- 姓名、住院号、门诊号、手机号、身份证号或设备可关联编号；
- 人体照片、视频、录音；
- 未完成脱敏审核的临床统计输出；
- 密钥、令牌、环境文件和本机绝对路径配置。

提交前应运行：

```bash
git status --short
git diff --cached
```

并确认暂存区不存在 `logs/`、`raw_txt/`、`qc_results/` 或临床工作簿。
