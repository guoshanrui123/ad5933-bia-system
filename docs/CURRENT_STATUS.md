## 校准边界

- 当前硬件配置下，独立负载验证支持5–25 kHz校准链路。
- 新人体记录仍可能落在电路负载凸包之外；域外结果属于外推，不能作为可靠绝对R/X。
- 医院预实验以10、15、20 kHz为核心频点，5和25 kHz用于边界探索。

## 作废规则

不得使用按 `R2 + (R1 ∥ C)` 计算的旧结果。当前结果必须采用：

```text
Zload = 1 / (1/R1 + 1/(R2 + 1/(j*2*pi*f*C)))
Ztotal = 10000 + Zload
```
